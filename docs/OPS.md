## Autonomy jobs

- Weekly cost/UX tuning job creates a proposal and prepares a PR branch.
  - Celery Beat: `weekly-cost-ux-tune` → `apps.api.tasks.autonomy.cost_ux_tune`
  - If `GH_TOKEN` and a remote are configured, the branch is pushed; otherwise it remains local and logs next steps.
  - PR titles must include `[FLAG:VOICE_AVATAR_MVP]` if routes or flags are touched.

## GH_TOKEN usage

- Export `GH_TOKEN` in the API/worker environment to enable PR creation/push.
- Host PR flusher will also read `~/.config/avatutor/gh_token`.
- Optional: set `CTO_GH_USER` in your shell so PRs auto-label `needs-CTO-review` and request a review from CTO.

## Chief of Staff cadence

- A 30-min progress report task summarizes autonomy commits in the last half hour and posts to Slack if `OPS_SLACK_WEBHOOK` set.
- Each report should include links to the latest app (`http://localhost:8080`) and any fresh PRs.
- Secrets are only read from environment variables; never commit credentials.

## Rollback

- Guardrails and canary tasks can automatically disable `VOICE_AVATAR_MVP` if error budgets are breached.
- Manual rollback: update the flag via `/flags` or via approval token flow at `/approve`.

## Ops Guide

- Feature flags via `/flags` endpoints or `opsctl`.
- Canary hooks and guardrails via event queries (p95 latency, error rate).
- Approvals are signed JWTs using `SECRET_KEY`. Generate with `scripts/gen_approval_link.py`.
- DLQ is stored in DB table `dlq`; use `opsctl dlq` to list/replay.
- Morning Brief is generated by Celery Beat and stored in MinIO.
- DB migrations: applied on API startup via `init_db()`; in containers, Alembic reads `DATABASE_URL` from env.

CLI examples (`opsctl`):

```
python opsctl/opsctl.py flags list
python opsctl/opsctl.py flags set VOICE_AVATAR_MVP --on
python opsctl/opsctl.py approve mint DEC-123 --action flip_flag --flag VOICE_AVATAR_MVP --percent 5
python opsctl/opsctl.py dlq list
python opsctl/opsctl.py jobs run morning-brief
```

### Health checks

- API: `curl -s http://localhost:8080/health | jq .`
- Flags: `curl -s http://localhost:8080/flags | jq .`

### Troubleshooting

- If the API container restarts with Alembic errors:
  - Bring the stack down with volumes: `docker compose -f infrastructure/docker-compose.yml down -v`
  - Bring up again: `docker compose -f infrastructure/docker-compose.yml up -d --build`
  - Ensure `.env` has `DATABASE_URL=postgresql+psycopg://app:app@db:5432/app`
